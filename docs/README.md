# Dokumentasi BANTUIN

Folder ini berisi dokumentasi proyek BANTUIN (platform jasa perbaikan rumah berbasis AI) dalam format Markdown.

## Isi

- **[PRD.md](PRD.md)** — Product Requirements Document / Software Requirements Specification (PRD/SRS) v1.0 DRAFT, November 2026. Berisi 58 kebutuhan fungsional (F-01–F-58), 27 kebutuhan non-fungsional (NF-01–NF-27), model data (34 tabel), batasan yang diketahui (termasuk K1–K3), dan lampiran. Versi berformat resmi adalah file DOCX/PDF.
- **[diagrams/](diagrams/)** — 21 diagram perancangan dari SDD v1.0 DRAFT (arsitektur, use case, activity, class, sequence, dan ERD). Lihat [indeks diagram](diagrams/README.md) untuk daftar lengkap beserta gambarnya.

## Catatan

- Folder `docs/ai/` yang sudah ada di repositori tidak disentuh oleh paket dokumentasi ini.
- Pembayaran pada diagram dan PRD ditandai **SIMULASI**: payment gateway nyata (F-31) belum terimplementasi dan endpoint `/pay` saat ini simulasi.
